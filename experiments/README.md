# Experiments Directory

This directory is for creating and testing new features, scripts, or strategies before integrating them into the main bot.

**Guidelines:**
1.  Isolate your tests here.
2.  Do not import main bot modules if you can avoid it, or be careful about side effects.
3.  Once a feature is verified here, it can be promoted to the main codebase.
